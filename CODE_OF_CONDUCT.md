# Code of conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be respectful, assume good faith, critique work rather than people, and make room
for people with less experience than you. Harassment, discrimination and personal attacks
are not welcome here.

## Scope

It applies in this repository's issues, pull requests, discussions and commit messages, and
anywhere someone is representing the project.

## Reporting

Report unacceptable behaviour privately through GitHub's private vulnerability reporting or
by contacting the maintainer through the GitHub account that owns this repository. Reports
are handled confidentially, and the maintainer will respond as promptly as a volunteer
project allows.

## Enforcement

Maintainers may edit or remove contributions, and may warn, temporarily block or permanently
block contributors whose behaviour violates this code. Decisions are explained to the person
concerned.
